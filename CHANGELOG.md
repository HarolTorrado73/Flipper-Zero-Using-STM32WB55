# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-05

### Added
- Initial release of DIY Flipper Zero with STM32WB55
- Complete step-by-step build guide (13 steps)
- OTP binary files for STM32WB55 configuration
- Momentum custom firmware (.dfu)
- SD Card contents (apps, assets, configs)
- Full pinout summary for all modules
- Wiring diagrams for:
  - Micro SD Module (SPI)
  - ST7565 LCD Display
  - CC1101 Sub-GHz Module
  - 6-button D-pad controls
  - Portable power supply (Li-Po + MT3608)
- Project preview image
