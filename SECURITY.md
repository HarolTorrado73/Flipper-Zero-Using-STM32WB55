# Security Policy

## Disclaimer

This project is for **educational purposes only**. It is designed to teach embedded systems, RF communication, and firmware development.

## Responsible Use

- Do **NOT** use this device to access systems or networks without authorization
- Do **NOT** use this device to intercept, jam, or replay RF signals illegally
- Always comply with local laws and regulations regarding RF transmission

## Reporting Security Issues

If you discover a security vulnerability in this project, please open an [Issue](../../issues) or contact the repository owner directly.
